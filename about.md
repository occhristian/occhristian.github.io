I’m Christian Okeke, a technical builder with strong interest in education, automation, crypto tooling, and practical web products.

My work usually sits at the point where software meets real human workflows: tutoring platforms, real estate dashboards, Telegram bots, WhatsApp automations, wallet trackers, deployment pipelines, and tutorials that help beginners understand what is going on.

I enjoy Python, Django, JavaScript, React, Node.js, APIs, background jobs, Docker, GitHub Pages, and cloud deployment. I also care about explaining things clearly, because a tool is only truly useful when people can understand and use it confidently.

## Strengths

- Debugging strange technical issues patiently
- Writing simple tutorials for beginners
- Building bots and automation systems
- Creating dashboards for real operations
- Teaching technical topics in plain English
